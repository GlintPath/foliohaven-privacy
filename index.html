笺栖隐私政策

最后更新：2026 年 5 月 29 日

English | 支持

1. 我们收集什么

笺栖只在你本地设备存储订单数据。我们不在服务端运行账户系统，没有“登录”。

2. iCloud 同步（可选）

如果你启用 iCloud 同步（Plus 功能），笺栖会通过 Apple 的 iCloud 服务把你的订单数据加密同步到你自己的 iCloud 账户。我们看不到这些数据，Apple 也不分享给我们。

3. CloudKit Public Database

笺栖使用 Apple 的 CloudKit Public Database 仅用于“首发会员”编号计数：

  • 购买 Plus 时写入一条 record，含：交易 ID、产品 ID、地区代码（如 "CN"）、购买时间、用户设备 ID 的不可逆哈希值
  • 我们不写入：你的姓名、邮箱、订单数据
  • 这些数据用于计数“你是全球第 X 位首发会员 / 地区第 Y 位”

4. 第三方

笺栖没有集成任何第三方 SDK，不向第三方分享数据。

5. 广告 / 追踪

笺栖不打广告，不追踪你的任何行为。

6. 数据删除

删除 app 即删除所有本地数据。iCloud 数据可通过 iOS 系统 Settings → Apple ID → iCloud → 管理存储 → 笺栖 → 删除数据。

7. Apple Account 验证（PIN 重置）

若你忘记 PIN，笺栖支持用 Sign In with Apple 验证身份。Apple 仅核实你确实拥有当前设备上的 Apple Account；我们不保存你的任何 Apple 凭证 / 姓名 / 邮箱 / 用户标识。验证完成即丢弃，仅用于授权一次性 PIN 重置。
